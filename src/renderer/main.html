Keyboard Shortcuts

Application Switching

Shortcut Description
Alt + Q Open application selector
Search and open new applications. Automatically restores minimized applications when opened.
Alt + T Open application switcher
Hold Alt and press T repeatedly to cycle through open applications. Automatically restores minimized applications when switched to.

Application Management

Shortcut Description
Alt + W Close current application
Automatically switches to another application if available
Alt + Z Minimize current application
Switches to next unminimized application, or shows main window if all are minimized
Alt + R Refresh current application
Reload the current page
Alt + D Toggle Developer Tools
Open/close developer tools for current application
